## Diagnostic (requêtes rejouées avec les clés de dev-keys.properties)

Cause racine unique : **les trois fournisseurs IA échouent pour des raisons de facturation**, l'app
retombe donc sur le résultat Pl@ntNet brut (sans description/santé/score IA) :

| Fournisseur | Réponse réelle |
|---|---|
| Claude | HTTP 400 — « credit balance is too low » (solde API épuisé ; l'abonnement Claude Pro n'inclut pas de crédits API) |
| Gemini | HTTP 429 — free tier `limit: 0` pour `gemini-2.0-flash` (quota gratuit supprimé pour ce modèle) |
| GPT | HTTP 429 — `insufficient_quota` (compte sans crédit) |

Le message « quota atteint » ne reflétait que le **dernier** fournisseur essayé, et le test de clé
des Paramètres validait des clés inutilisables (listage de modèles au lieu d'une génération).

## Fait

1. **`AiModels.kt`** : nouveau motif `AiFailureReason.BILLING` ; libellés centralisés
   (`AiFailureReason.label()`) ; `ProviderFailure` + `List<ProviderFailure>.summary()` pour des
   messages par fournisseur (« Claude : crédit épuisé · Gemini : quota atteint »).
2. **`HttpSupport.kt`** : classification tenant compte du corps — 400 « credit balance » (Anthropic)
   et 429 « insufficient_quota » (OpenAI) → `BILLING` au lieu de `UNKNOWN`/`QUOTA`.
3. **`AiOrchestrator.kt`** : `AllFailed` porte la liste des échecs par fournisseur (analyse et Q&A),
   `lastReason` conservé en propriété dérivée pour le choix du `FailureKind`.
4. **Messages** (`IdentificationRepository`, `PlantQaViewModel`, `SettingsViewModel`) : détail par
   fournisseur partout ; le test de clé distingue « clé acceptée mais crédit épuisé ».
5. **Tests de clé réels** : `GeminiClient.testKey` et `OpenAiClient.testKey` font une
   mini-génération (`maxOutputTokens: 1`) au lieu de lister les modèles — fini les « Clé valide »
   pour des clés sans crédit de génération.
6. **`GeminiClient.MODEL`** : `gemini-2.0-flash` → **`gemini-flash-latest`** (alias qui conserve un
   quota gratuit). Vérifié par requêtes directes avec la clé du projet : texte HTTP 200, vision
   (`inline_data`) HTTP 200. **Ceci débloque l'analyse IA sans payer.**
