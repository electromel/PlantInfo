# Release 0.7.1 (versionCode 12)

Motif : la Play Console signale « Obscurcissement (0 %) », sous son seuil de 25 %, avec une date
limite. Le build release n'était pas minifié.

- `versionCode` 11 → **12**, `versionName` **0.7.1**.
- R8 activé sur le build release (réduction, obscurcissement, retrait des ressources). Le
  `mapping.txt` est embarqué dans le bundle : rien à téléverser à part.
- Variante `minified` pour essayer le build publié sur le téléphone (voir `CLAUDE.md`).
- Contenu fonctionnel : itérations 1 à 4 de l'audit v2 (voir `2026.11.10-Audit v2 - rapport.md`) :
  toxicité de l'espèce retenue, « Tout supprimer » et ses photos, robustesse face aux réponses
  d'IA illisibles, alerte de clé en mode « Gemini seul », textes de confidentialité.
- `docs/play-store-listing.md` : notes 0.7.1 dans les cinq langues.
- Aucune migration de base (schéma inchangé, version 11).
- Essais sous R8 sur le Pixel (variante `minified`) : assistant, fiche par nom, question à l'IA,
  PDF, partage, changement de langue, sans erreur. Appareil photo et galerie non rejoués.
- Après la construction du bundle : la variante `minified` est renommée « PlantInfo (R8) » et porte
  un filigrane. Le build release n'est pas modifié par ce changement.
- `ACCESS_MEDIA_LOCATION` retirée (constat F20 de l'audit) : depuis Android 14, la demander affichait
  « Autoriser PlantInfo à accéder aux photos et vidéos » au premier lancement. Contrepartie
  acceptée : une photo importée peut arriver sans son lieu de prise de vue. Bundle reconstruit
  avec le même versionCode 12, le précédent n'ayant pas été téléversé. Non testé sur appareil.
