# 2026.09.21 — Release 0.5.0 (versionCode 5)

## Demande

Commiter, pousser, produire une version pour le Play Store et fournir les textes de la fiche.

## Contenu de la version

- **Multilangue** : français, anglais, allemand, italien, espagnol — interface, messages et fiches
  rédigées par l'IA. Voir `log/2026.09.19-Support multilangue.md`.
- **Nouvelle icône** : un viseur qui cadre une feuille. Voir
  `log/2026.09.19-Nouvelle icone viseur et feuille.md`.

## Fait

- `versionCode` 4 → **5**, `versionName` **0.5.0**. L'historique des numéros est commenté dans
  `app/build.gradle.kts` : un versionCode ne peut jamais être réutilisé sur la Console.
- Trois commits poussés sur `origin/main` : icône, support multilangue, release.
- **Bundle signé** : `app/build/outputs/bundle/release/app-release.aab` (15,3 Mo),
  `jarsigner -verify` → « jar verified ». Les cinq langues sont présentes dans la table de
  ressources du bundle (vérifié en cherchant « Einstellungen », « Impostazioni », « Ajustes »,
  « Paramètres » et « Settings » dans `base/resources.pb`).
- `docs/play-store-listing.md` réécrit : titre, description courte, description complète et notes de
  version **dans les cinq langues**, chacun contrôlé contre les limites de la Console
  (30 / 80 / 4000 / 500 caractères).

## Vérification

`:app:testDebugUnitTest`, `:app:lintVitalRelease` (qui porte `MissingTranslation`) et
`:app:bundleRelease` après `clean` : tous au vert. `python tools/check_translations.py` : OK.

## À faire dans la Console

1. Téléverser l'AAB sur la piste voulue (test interne jusqu'ici).
2. Ajouter les langues **en-US, de-DE, it-IT, es-ES** à la fiche et y coller les textes du document ;
   fr-FR reste la langue par défaut.
3. Coller les notes de version 0.5.0 de chaque langue.
4. Les captures d'écran sont encore en français pour toutes les langues : la Console l'accepte, mais
   un jeu par langue serait plus convaincant.

## Non versionné

Le dossier `notes/` (planches d'icônes, brouillons) reste hors du dépôt, comme avant ce lot.
