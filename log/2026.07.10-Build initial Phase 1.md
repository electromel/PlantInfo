# 2026.07.10 — Build initial (Phase 1 / MVP)

## Demandes reçues

Création *from scratch* d'une application Android native d'identification de plantes, arbres et
champignons (cahier des charges complet fourni). Décisions validées avec l'utilisateur avant le
développement :

- **Carte** : OpenStreetMap via **osmdroid** (libre, sans clé Google).
- **Livraison** : **par phases**, MVP d'abord.
- **minSdk** : **API 29 (Android 10)**, targetSdk 35.

## Ce qui a été réalisé (Phase 1)

Socle applicatif complet et pipeline d'identification de bout en bout :

1. **Échafaudage Gradle** : version catalog (`gradle/libs.versions.toml`), `build.gradle.kts` racine +
   `app`, `settings.gradle.kts`, `gradle.properties`, `.gitignore`, manifeste + permissions
   (caméra, localisation fine/approx, internet, notifications), thème Compose accessible (typographie
   agrandie, palette contrastée).
2. **Clés API** (`data/keys/`) : `ApiKeyStore` sur `EncryptedSharedPreferences` (Android Keystore),
   pré-remplissage depuis `dev-keys.properties` → `BuildConfig` sans écraser une clé saisie, ordre de
   repli IA configurable.
3. **Écran Paramètres** : saisie + collage presse-papier + **test immédiat** de chaque clé + liens
   vers les pages de création + réordonnancement de l'ordre de repli.
4. **Capture** (`ui/capture/`) : CameraX (`LifecycleCameraController`), import galerie
   (`PickVisualMedia`), compression JPEG (≤1600 px, EXIF corrigé) via `ImageStorage`, GPS/altitude/
   précision via `LocationProvider`, sélection d'organe par photo, photos complémentaires.
5. **Pipeline** (`data/remote/`, `data/repo/`, `domain/`) : client Pl@ntNet (multipart), interface
   `AiProvider` + clients Claude/Gemini/GPT, `AiOrchestrator` (repli), `ConfidenceEngine` (fusion des
   scores + détection de divergence + demande de photo complémentaire), `IdentificationRepository`.
6. **Persistance** (`data/db/`) : Room (entité historique conforme au §4), `HistoryRepository`.
7. **Résultat / Historique / Détail** (`ui/`) : fiche complète (score /100, avertissement champignon
   systématique, alerte espèce protégée, divergence de sources, habitat, santé + recommandations,
   infos, alternatives, coordonnées), liste filtrable (recherche + favoris), suppression unitaire et
   totale (avec confirmation), favoris + notes.

## Choix techniques et justifications

- **Aucun backend** : appels directs aux API depuis l'appareil (choix du cahier des charges) →
  OkHttp + kotlinx.serialization, clés chiffrées localement.
- **Repli IA au niveau orchestrateur** : chaque client expose une interface commune ; la logique de
  bascule (clé absente/invalide, quota, réseau, serveur) est centralisée et testable indépendamment.
- **`ConfidenceEngine` séparé** (logique pure) : le score final combine Pl@ntNet et IA selon leur
  accord/désaccord ; testable sans appareil ni réseau (cible de tests unitaires Phase 1+).
- **Score persisté, pas la demande de photo complémentaire** : cette dernière n'a de sens qu'au moment
  de l'identification ; en historique on la re-dérive du seuil de score.
- **osmdroid** retenu (vs Google Maps) pour rester libre et sans compte/facturation Google Cloud.
- **WorkManager via `Configuration.Provider` + Hilt** : initialiseur `androidx.startup` retiré du
  manifeste pour éviter un double init (la file hors-ligne réelle arrive en Phase 3).

## Points ouverts / reportés

- **Compilation non effectuée ici** : l'environnement de dev (poste courant) n'a ni Android SDK ni
  Gradle installés (JDK 25 seul). Le build/APK et la vérification runtime doivent être faits dans
  Android Studio (JDK 17 embarqué). Voir README.
- `gradle-wrapper.jar` non versionné (binaire) : régénéré par Android Studio ou `gradle wrapper`.
- **Phase 2** : carte osmdroid interactive, aire de répartition GBIF (cache par espèce, entité
  `SpeciesRangeCacheEntity` + migration Room v2), rayon d'incertitude affiché.
- **Phase 3** : file d'attente hors-ligne + notifications ; liste de référence des espèces protégées
  en Suisse ; guidage renforcé des photos complémentaires.
- **Phase 4** : export PDF, partage natif Android, filtres date/lieu avancés, accessibilité renforcée.
- Surface d'amélioration : le message d'info « aucune clé IA / IA en échec » (renvoyé par le pipeline)
  n'est pas encore affiché après navigation vers le résultat (le bandeau « Pl@ntNet seul » le supplée).
