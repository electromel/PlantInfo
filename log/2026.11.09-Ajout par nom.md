# 2026-11-09 — Ajout d'une plante par son nom

## Demande
Pouvoir ajouter une plante par son nom : photo cherchée sur le web, puis même traitement que
l'existant, sans santé ni lieu de prise de vue.

## Fait
- `data/remote/web/WebPhotoClient` : image principale de l'article Wikipédia (langue de l'app, puis
  anglais), sans clé ; les SVG sont écartés.
- `IdentificationRepository.identifyByName` : photo → `ImageStorage.saveFromBytes` → pipeline
  habituel avec `queriedName` (prompt `AiPrompt` : pas de santé, pas de photos à demander, pas de lieu).
- `queriedName` traverse request/résultat/entité (Room v11, migration 10→11), worker, relance.
- UI : bouton « Par nom » + dialogue sur l'écran Capture ; note sur la fiche. 5 langues.

## Vérification
`:app:testDebugUnitTest` + `assembleDebug` OK ; installé sur Pixel (variante debug). Pas de test
automatisé du client Wikipédia (réseau).
